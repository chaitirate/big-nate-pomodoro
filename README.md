# Pomodoro Clock
**Version 1.0**

A spin on the classic Pomodoro timer ⏰

This is a simple web app with:
- a countdown timer for work and break sessions
- adjustable work and break durations
- selectable background sounds (rain, cafe, fire)
- start, pause, and reset controls

## Run it locally
1. Open `index.html` in your browser.
2. Adjust the `Work` and `Break` minutes.
3. Choose a sound from the dropdown.
4. Press `Start` to begin the timer.

## Files
- `index.html` — structure and controls
- `styles.css` — styling and layout
- `script.js` — timer logic and audio handling
- `assets/` — sound files used by the app
